NowoPdfEditorBundle registered. Install the free Python engine:

    python3 -m pip install pymupdf
    php bin/console nowo:pdf-editor:check-engine

Protect the editor in config/packages/security.yaml (the bundle also checks nowo_pdf_editor.security.access_roles):

    access_control:
        - { path: ^/pdf-editor, roles: ROLE_ADMIN }

Point nowo_ui_kit.layouts.admin at your layout (or a bridge) so the editor pages render inside your chrome.
