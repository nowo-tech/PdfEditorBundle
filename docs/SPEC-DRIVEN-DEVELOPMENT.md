# Spec-driven development

This package follows the Nowo spec-driven pattern (REQ-DOCS-013 / REQ-SPECKIT).

1. Product behaviour lives in `specs/001-baseline/spec.md`.
2. A categorized inventory of `src/` lives in `specs/001-baseline/code-inventory.md`.
3. Implementation changes should update both documents in the same change.

Constitution and Spec Kit templates: `.specify/`.
