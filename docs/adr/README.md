# Architecture Decision Records

Decisions that affect PdfEditorBundle structure, runtime, and editor experience.

| ADR | Title | Status |
|-----|-------|--------|
| [0001](./0001-unified-editor-ux-ui.md) | Unified editor shell — UX & UI | Accepted |

## Format

Each ADR follows:

1. **Context** — problem and constraints  
2. **Decision** — what we chose  
3. **UX / UI principles** — user-facing rules  
4. **Consequences** — trade-offs and follow-ups  

New ADRs increment the number and live in this folder.
