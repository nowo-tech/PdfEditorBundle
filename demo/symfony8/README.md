# PDF Editor Bundle — Symfony 8.1 demo

FrankenPHP demo on **Symfony 8.1** and PHP 8.4+. From this directory:

```bash
make up
```

Default URL: **http://localhost:8031** (redirects to `/pdf-editor`).

Requires **Python 3 + PyMuPDF** inside the container (installed in the image). Upload a PDF and use the visual editor; changes are sent to the Python engine when you click **Save to PDF**.
